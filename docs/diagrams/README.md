# `docs/diagrams/`

References for visual explanations of the template-system architecture. Open `.excalidraw` files with [Excalidraw](https://excalidraw.com) or the Excalidraw VS Code / Obsidian extension.

## Markdown wireframe

- [Annotated editor-to-publication wireframe](../ARCHITECTURE.md#11-annotated-wireframe-editor-to-publication) — the in-document reference for shared Template preset, Gaya panel, Section stack, Variant gallery, draft, Live preview, and published-card terms and state flow.

This documentation set deliberately uses an accessible Markdown wireframe; it does not create or modify an `.excalidraw` asset.

## Drawn diagrams (repository root)

- `kamy-jemput.excalidraw` — the original user-drawn sketch of Section components. Source of truth for the initial component list.
- `flow.excalidraw` — system flow sketch.

When adding a diagram here, also link to it from the relevant `.md` file (e.g. `ARCHITECTURE.md` linking to `diagrams/<file>.excalidraw`). Do not list diagram assets that do not exist in the repository.
